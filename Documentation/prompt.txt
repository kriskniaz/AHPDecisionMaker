Project AHP Website Application

	- General Information
		○ I would like to create a web interface application for my ahp library.  The library is located in the pCode repository, the AHP Visual Studio project
		○ An user of this application will work with AHP projects and AHP models.
		○ The AHP calculation business logic will be provided by the existing AHP library
		○ Additional middleware needs to be generated in C#
		○ Microsoft SQL server will be the data base
		○ Web pages will be in ASP.NET Core MVC with Razor Views
		○ The website application will have its own Middleware that will allow the projects and models to be saved to data base and retrieved from data base.
		○ The middleware will consist of entities 
		○ Entities will have corresponding tables in the data base
		○ The existing AHP library has definition for Model = AHPObjectModel, Goal, Criteria and alternatives,
		so a translaton layer between new entities and existing AHP classes needs to be created.
	- Entities
		○ Project: The AHP project will have following attributes:
			- Project Id 
			- Project goal a string, for example "Selection of best automobile"
			- Project description - free text to add more info about the project
			- Decision Model
			- Create Date
			- Last update date
		○ Model: A Decision model will have following attributes
			- Model Id
			- Goal
			- Collection of decision criteria
			- Collection of alternatives
			- Only 1 set of decision criteria and 1 set of alternatives is supported, as per pCode library
			- Collection of AHP pairwise comparisons between decision criteria with respect to the goal
			- Collection of AHP pairwise comparisons of alternatives with respect to each criteria
		○ Criterion: Decision criterion will have the following attributes
			- Criterion Id
			- Name
		○ Alternative: Alternative attributes
			- Alternative id
			- Name
	- Web Interface
		○ The application will have following pages
			- Projects
			- Add new project
			- Edit project
			- Add new model
			- Edit model
		○ Application will have navigation with two links: Projects page and Add new Project
		○ The projects page will the starting page of the application
		○ The Projects page shows all projects saved into the data base
			- The projects are shown as a table 
			- Each row in the table will have following fields - columns: project name, create date, last update date, action fields - edit, delete
			- The table is sortable by the create date and separately by last update date
			- After clicking on the edit button the is redirected to the project edit page for this project
			- After clicking on the delete button the project and the associated models are removed from the data base and the page refreshes
		○ After clicking on the create new project page the user is redirected to the new project page
		○ On the new project page
			- The user can enter simple attributes of the project
			- The user can also click on add model link which will take the user to the new Model page
			- The new model will be associated to this project
		○ The Model page will have two views available as tabs: the edit model view and perform comparisons view
			- On the edit model view page	
			- 	the user can add a goal
			-	the user can add decision criterias and alternatives
			- The mockup for the perform comparisons page is shown in the /Documentation/ahp-car-selection.html file
			- The criteria and alternatives are taken dynamically from the edit model tab
